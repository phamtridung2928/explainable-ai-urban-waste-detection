# Results

## Metrics reported in the manuscript

| Metric | DT+BPSO baseline | Proposed framework | Difference |
|---|---:|---:|---:|
| Accuracy | 91.24% | 98.46% | +7.22 percentage points |
| Precision | 90.78% | 97.42% | +6.64 percentage points |
| Recall | 89.95% | 97.18% | +7.23 percentage points |
| F1-score | 90.36% | 97.30% | +6.94 percentage points |
| AUC-ROC | 0.93 | 0.98 | +0.05 |
| MCC | 0.87 | 0.95 | +0.08 |

The difference in accuracy is 98.46 − 91.24 = **7.22 percentage points**.

## Interpretation

The manuscript reports higher scores for the proposed framework than for its DT+BPSO comparison baseline across all listed metrics. It also reports that bin fill level, waste weight, and overflow count/frequency are the leading SHAP features.

## Reproducibility status

These numbers are transcribed from the paper. They have not been generated by code in this repository and should not be described as independently verified results.

Recommended next steps:
1. Recreate the baseline under the same split and preprocessing.
2. Record seeds and all configuration details.
3. Report a confusion matrix and per-class metrics.
4. Run repeated experiments or cross-validation where appropriate.
5. Add ablation studies to measure the contribution of SAE, EARO, GANet, and SHAP-related design choices.
