# Dataset

The research paper identifies the source as the Kaggle Waste Management Dataset:

https://www.kaggle.com/datasets/commcollabs/waste-management-dataset/data

The paper reports 20,000 observations and 48 columns. It describes waste-bin measurements, environmental conditions, traffic, population characteristics, land use, road-network indicators, historical collection statistics, temporal information, and a `waste_hotspot_level` target.

## Important

- Dataset files are not included in this repository.
- Download the dataset from the original source and comply with its license and terms.
- Verify the actual column names, label definitions, missingness, class balance, and geographic meaning before modeling.
- Do not assume that the data represents live sensor feeds or a deployed municipal system.
- Record the downloaded version and a file checksum when building a reproducible experiment.
